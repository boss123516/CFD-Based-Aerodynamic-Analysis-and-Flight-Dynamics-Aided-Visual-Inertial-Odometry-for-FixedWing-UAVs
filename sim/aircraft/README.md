# Aircraft models

The public smoke test uses the bundled JSBSim C172p. It is not the research aircraft.

The research aircraft is an owner-purchased SUPER STINGRAY currently being built.
Its CAD, manufacturing files, dimensions, mass/inertia, aircraft-specific coefficients
and derived flight models are kept in a separate private workspace. Do not commit them here.
Only owner-approved flattened aircraft images may be published.

Aircraft-specific CFD analysis and model validation have not been completed.
